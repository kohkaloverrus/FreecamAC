# Вклад в проект

1. Сделайте форк репозитория и создайте ветку: `git checkout -b feature/my-feature`
2. Соберите проект: `mvn clean package` — сборка должна проходить
3. Отправьте PR с описанием изменений (шаблон в `.github/PULL_REQUEST_TEMPLATE.md`)

Стиль: Java 21, 4-пробельная индентация, комментарии на русском допустимы.
