# XRay & Freecam AntiCheat for Paper 1.21.1

## Описание
Плагин защищает от читов X-Ray и Freecam, подменяя для клиента все блоки вне зоны видимости на камень.

## Принцип работы
- **Freecam**: игрок не видит сквозь стены — всё непрогруженное/невидимое заменяется камнем
- **X-Ray**: текстурпак делает камень прозрачным, но античит подменяет скрытые руды за стенами на камень в пакете ChunkData
- Прозрачные блоки (стекло, листва и т.д.) остаются видимыми только если клиент реально может видеть что за ними
- Камень не появляется там, где игрок уже был
- Камень не появляется за листвой/деревом на поверхности
- Защита действует только дальше 30 блоков от игрока (или 5/10 блоков при сплошных стенах)

## Сборка
```bash
mvn clean package
```

## Установка
Скопируйте `target/xray-freecam-anticheat-1.0.0.jar` в папку `plugins/` сервера Paper 1.21.1.

## Команды
- `/anticheat enable|disable|status|reload` (anticheat.admin)

## Права
- `anticheat.admin` — управление плагином
- `anticheat.bypass` — обход защиты
